# 콘텐츠 제작 운영 관리 시스템 (목업)

숙소·공간 콘텐츠 제작팀의 업무 흐름을 한눈에 파악하고 관리하는 내부용 웹 목업입니다.

```
촬영 일정 관리 → 촬영 사진 업로드 → 사진 보정 및 검수 → 각 채널별 콘텐츠 업로드
```

이 4단계가 **현황판 보드의 칼럼 4개**이자 **콘텐츠 상세의 탭 4개**입니다.

## AX 토글

사이드바에 **AX 개선 아이디어** 토글이 있습니다. 이 목업의 핵심 장치입니다.

| 토글 | 화면 |
|---|---|
| **끄면** | 지금 쓰고 있을 법한 관리 화면. AI가 만든 신호가 전부 사라집니다 |
| **켜면** | 각 단계에 AI 또는 자동화를 어디에 넣을지, 무엇이 바뀌는지 |

As-Is와 To-Be를 같은 화면에서 비교할 수 있게 만든 것이라, 토글을 껐다 켜면서 보시면 제안의 범위가 바로 드러납니다.

## 화면

| 경로 | 내용 |
|---|---|
| `/` | **현황판.** 지표 4개 + 4단계 보드 + 단계별 소요일 + 정체 알림 |
| `/calendar` | 촬영 캘린더. 날짜의 `+` 로 일정 등록 (하루 여러 건 가능) |
| `/accommodations` | 숙소 등록·수정. 시설을 고르면 촬영 필수 컷이 자동 생성됨. 촬영 컷 규칙도 여기서 관리 |
| `/content/[id]` | **콘텐츠 상세.** 촬영 일정 / 사진 업로드 / 보정·검수 / 채널 발행 4탭 |
| `/ax` | AX 개선 아이디어 9개 · 처리 비용 · AI가 못 하는 것 |

등록 흐름은 실제로 동작합니다. 시설 규칙을 바꾸면 숙소의 체크리스트가 바뀌고, 숙소를 저장하면 목록에 추가되고, 촬영 일정을 등록하면 현황판 보드와 캘린더에 나타납니다. 서버가 없어 새로고침하면 초기값으로 돌아갑니다.

## AX 관점: AI를 쓰는 곳 / 안 쓰는 곳

**관리 화면 자체에는 AI를 넣지 않았습니다.** 보드·캘린더·상태 배지·발행 링크 기록은 전부 쿼리와 조건 분기입니다. 여기에 AI를 붙이면 억지입니다. AI는 관리 대상인 노동 안에 있고, 관리 화면은 그 결과를 신호로 띄웁니다.

9개 개선 지점 중 **4개는 AI를 쓰지 않습니다.**

| 단계 | 개선 지점 | 수단 |
|---|---|---|
| 촬영 | 필수 컷 목록 자동 생성 | **AI 아님** — 규칙 |
| 업로드 | 촬영 누락 탐지 | LLM 비전 + 배열 대조 |
| 업로드 | 셀렉 후보 800 → 82장 | 연산 → 전용 모델 → LLM 비전 |
| 보정·검수 | 1차 검수 플래그 | **AI 아님** — 허프 변환·히스토그램 |
| 보정·검수 | 리터처 간 톤 편차 | **AI 아님** — RGB 평균 비교 |
| 발행 | 채널별 규격 변환 | 전용 모델 (객체 검출) |
| 발행 | 채널별 카피 초안 | LLM |
| 전 구간 | 정체 알림 | **AI 아님** — 쿼리 + 스케줄러 |
| 확장 | 반려 사유 패턴 요약 | LLM |

### 처리 순서가 비용입니다

```
사진 800장
  ↓ [연산]      결함 필터 · 3초        흔들림 34, 노출 8 제외 → 758장
  ↓ [전용 모델]  중복 제거 · 41초       유사 컷 412 제외 → 346장
  ↓ [LLM 비전]  공간 분류 · 2분 18초   중복 그룹은 대표 1장만 분류 후 상속
대표 컷 82장
```

346장을 긴 변 768px로 줄여 분류하면 **한 건당 약 $0.23** (Haiku 4.5 + 배치). 월 30건이면 만 원 안팎입니다. 800장을 원본 해상도로 전부 던지면 10배 이상이 됩니다.

### AI가 못 하는 것

객실 등급·호수는 **판정할 수 없습니다.** 스탠다드룸인지 디럭스룸인지는 그 숙소가 정한 상품명이지 시각적 속성이 아니고, 같은 숙소의 객실 두 장을 놓고 어느 쪽이 몇 번인지 가릴 근거가 이미지에 없습니다.

그래서 체크리스트를 `객실 5컷 × 객실 수` 로 합산해서 관리합니다. 확인해 주는 것은 "객실로 분류된 컷이 10장 있다"까지이고, 그 10장이 두 객실에 고르게 퍼졌는지는 촬영자가 챙겨야 합니다.

## 목업 범위

- 서버, DB, 로그인, 실제 AI 호출은 구현하지 않았습니다
- 데이터는 `src/data/*.ts` 에 있고, 실제 DB 스키마와 형태를 맞췄습니다
- 사진은 라벨명이 적힌 회색 자리표시자입니다
- AI 산출물에는 `AI 결과 (모의)` 배지를 붙였습니다

## 실행

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

Next.js 16 (App Router) · TypeScript · Tailwind CSS v4. 상태관리 라이브러리 없음 (Context + `useState`).
